## 문제 요약

앨리스와 밥이 각각 $N$개, $M$개의 정수 쌍을 가지고 있습니다. 앨리스가 먼저 각 쌍마다 정수 하나를 골라 모두 XOR해 제출합니다. 밥은 앨리스가 제출한 값을 확인하고 같은 행동을 해 두 값을 XOR합니다. 앨리스는 최종 값을 최대화, 밥은 최소화하고자 합니다. 최종 값을 구하세요.

## 풀이

각 정수 쌍 $(x, y)$마다 일단 $x$를 답에 XOR하고 $x \oplus y$를 고를지 말지 고르는 문제로 바꿉니다. 이제 앨리스와 밥 각각이 만들 수 있는 수의 XOR 기저만 관리하면 됩니다.

되도록 그리디하게 자릿수가 큰 비트를 원하는 쪽으로 조작하는 것이 최소화든 최대화든 유리합니다. 큰 비트부터 내려가면서 앨리스와 밥이 각각 그 비트를 조작할 수 있는지 확인합니다. 둘 중 한쪽만 조작할 수 있는 경우는 간단합니다.

앨리스와 밥이 모두 조작할 수 있는 경우 결론적으로 해당 비트가 0이 되는 건 고정이지만 앨리스의 행동에 따라 밥의 조작 여부가 결정됩니다. 따라서 앨리스에게 두 조작을 합친 새로운 조작을 쥐어주면 됩니다.

테스트 케이스 당 시간 복잡도 ${\cal O}((N+M) \lg |x|)$에 문제를 해결할 수 있습니다.

## 코드

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

struct xor_basis{
	ll basis[64] = {};
	void add(ll x){
		for(int i = 60; i >= 0; i--) if(x&(1LL<<i)){
			if(basis[i]) x ^= basis[i];
			else{basis[i] = x; break;}
		}
	}
};

void solve(){
	xor_basis A, B; ll tot = 0;
	int n, m; cin >> n >> m; while(n--){
		ll a, b; cin >> a >> b; tot ^= a; A.add(a^b);
	} while(m--){
		ll a, b; cin >> a >> b; tot ^= a; B.add(a^b);
	}
	
	for(int i = 60; i >= 0; i--){
		if(A.basis[i] && B.basis[i]){
			// A can choose how to make it 0
			if(tot&(1LL<<i)) tot ^= A.basis[i];
			ll choice = A.basis[i]^B.basis[i];
			A.basis[i] = 0; A.add(choice);
		}
		else if(A.basis[i]){
			if(~tot&(1LL<<i)) tot ^= A.basis[i]; A.basis[i] = 0;
		}
		else if(B.basis[i]){
			if(tot&(1LL<<i)) tot ^= B.basis[i]; B.basis[i] = 0;
		}
	}
	
	cout << tot << '\n';
}

int main(){
	cin.tie(0);cout.tie(0);ios::sync_with_stdio(false);
	int T; cin >> T; while(T--) solve();
}
```
