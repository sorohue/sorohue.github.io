[문제 링크](https://www.acmicpc.net/problem/17149)입니다.

## 문제 요약

$N$명의 선수의 3개 종목 각각에 대한 등수가 주어집니다. 각 등수는 update될 수 있습니다.

두 선수와 경기 종목을 골라 진 선수를 탈락시킬 수 있습니다. 선수에 대한 쿼리가 주어지면 대결할 선수와 종목을 적절히 선택했을 때 그 선수를 우승시킬 수 있는지 판정해야 합니다.

## 풀이

Claim: 모든 종목에서 $1$등부터 $K$등까지가 특정 $K$명 안에서 나오게 되는 가장 작은 $K$를 $K_{min}$이라고 합시다. **어떤 선수의 등수가 $K_{min}$등 이하임과 그 선수가 우승할 수 있음이 동치입니다.**

<details>
<summary>증명</summary>
<div markdown="1">

등수가 $K_{min}$등 초과인 선수는 위의 $K_{min}$명의 선수 중 누구와 어떻게 대결해도 집니다. 따라서 우승할 수 없습니다.

$K_{min}$등 안에 든 아무 선수를 생각합니다. 그 선수가 종목 $A$에서 $1$등이 아니라면 자신보다 종목 $A$를 잘하는 선수 중 다른 종목으로 이길 수 있는 선수가 반드시 존재합니다. 그렇지 않은 경우 해당 인원들끼리 $1$등부터 $K' < K_{min}$등을 다 먹었다는 의미라 $K_{min}$이 최소임에 모순입니다.

반복하여 종목 $A$에서 $1$등인 선수를 찾았다고 합시다. 이제 나머지 모두를 종목 $A$로 탈락시키고 아까 찾아두었던 선수들을 역순으로 대결시켜서 $A$ 종목 $1$등 부터 차례로 탈락시키면 원하는 선수를 반드시 우승시킬 수 있습니다.

</div>
</details>

따라서 그러한 $K_{min}$을 빠르게 찾을 수 있으면 됩니다. 가능한 방법은 여러 가지가 있습니다.

아래의 구현체는 $d[a[i]] := 2a[i]-b[i]-c[i]$를 관리합니다. $a, b, c$는 각각의 종목에서 선수 $i$의 등수, $d$는 종목 $A$에서 $a[i]$등을 한 선수에 관련된 값입니다.
$a[i]$ 순으로 인덱스를 정렬하면 $b[i]$와 $c[i]$의 누적 합은 각각 $a[i]$의 누적 합 이상이며, 둘이 같아지는 건 $b$나 $c$도 각각 $1$등부터 차례대로 모두 등장했을 때뿐입니다. 따라서 누적 합이 $0$이 되는 최초의 지점이 $K_{min}$입니다.

walk on segtree를 적당히 구현하면 총 시간 복잡도 ${\cal O}(N+Q \lg N)$에 문제를 해결할 수 있습니다.

## 코드

```cpp
#include<bits/stdc++.h>
#define mid (l+r>>1)
using namespace std;
using ll = long long;

int n;
ll a[101010], b[101010], c[101010], d[101010];

struct Node{
	ll sum, pfxmin;
} tree[404040];

void init(int now, int l, int r){
	if(l == r){tree[now] = {d[l], d[l]}; return;}
	init(now<<1, l, mid); init(now<<1|1, mid+1, r);
	tree[now] = {tree[now<<1].sum+tree[now<<1|1].sum, min(tree[now<<1].pfxmin, tree[now<<1].sum+min(0LL, tree[now<<1|1].pfxmin))};
}

int walk(int now, int l, int r, ll offset){
	if(l == r) return l;
	if(offset+tree[now<<1].pfxmin == 0) return walk(now<<1, l, mid, offset);
	return walk(now<<1|1, mid+1, r, offset+tree[now<<1].sum);
}

void upd(int now, int l, int r, int i){
	if(l == r){tree[now] = {d[l], d[l]}; return;}
	if(i <= mid) upd(now<<1, l, mid, i);
	else upd(now<<1|1, mid+1, r, i);
	tree[now] = {tree[now<<1].sum+tree[now<<1|1].sum, min(tree[now<<1].pfxmin, tree[now<<1].sum+min(0LL, tree[now<<1|1].pfxmin))};
}

void init_rank(vector<int> A, vector<int> B, vector<int> C){
	n = A.size();
	for(int i = 0; i < n; i++) a[A[i]] = i, b[B[i]] = i, c[C[i]] = i;
	for(int i = 0; i < n; i++) d[a[i]] = b[i]+c[i]-2*a[i];
	init(1, 0, n-1);
}

void update_rank(int court, int i, int j){
    if(court == 1) swap(a[i], a[j]);
    if(court == 2) swap(b[i], b[j]);
	if(court == 3) swap(c[i], c[j]);
	d[a[i]] = b[i]+c[i]-2*a[i]; upd(1, 0, n-1, a[i]);
	d[a[j]] = b[j]+c[j]-2*a[j]; upd(1, 0, n-1, a[j]);
}

bool can_win(int x){
    return a[x] <= walk(1, 0, n-1, 0);
}

int main(){
	cin.tie(0);cout.tie(0);ios::sync_with_stdio(false);
	int n, q; cin >> n >> q; vector<int> A(n), B(n), C(n);
	for(auto& i : A) cin >> i, i--; for(auto& i : B) cin >> i, i--; for(auto& i : C) cin >> i, i--;
	init_rank(A, B, C);
	while(q--){
		int op; cin >> op; if(op == 1){
			int x; cin >> x; x--; cout << (can_win(x) ? "DA\n":"NE\n");
		} if(op == 2){
			int c, i, j; cin >> c >> i >> j; i--; j--; update_rank(c, i, j);
		}
	}
}
```
