[문제 링크](https://www.acmicpc.net/problem/17149)입니다.

## 문제 요약

길이 $N$의 원순열 $A$와 정수 $k \le N$에 대해 $f(A[i]) := A[i] \oplus A[i+1] \oplus \cdots \oplus A[i+k-1]$로 정의합니다. $T \le 10^{18}$에 대해 $f^{T}(A[0 \dots N-1])$를 구하세요.

## 풀이

$f(f(A[0])) = \bigoplus_{i=0}^{k-1} \bigoplus_{j=0}^{k-1} A[i+j]$입니다. $i \neq j$인 경우 $(i, j)$와 $(j, i)$가 같은 $A[i+j]$를 내놓으니 소거하면 $f^{2}(A[0]) = \bigoplus_{i=0}^{k-1} A[2i]$임을 알 수 있습니다. 같은 논리로 $f^{2^X}$는 $2^X$칸씩 건너뛰어 XOR하는 연산임을 알 수 있습니다.

$d = 2^X \mod N$가 주어질 때 $f^{d}(A)$를 빠르게 구합시다. 원순열을 $\gcd(N, d)$개의 길이 $L = {N \over \gcd(N, d)}$짜리 사이클로 나눕니다. 각 사이클은 $f(d)$에서 서로 완전 독립입니다.

$K = 2L$이라고 생각하면 사이클 위에서 모든 원소를 두 번씩 XOR할 겁니다. 따라서 $K \mod 2L$개의 원소만 누적 XOR을 취해도 좋습니다. 슬라이딩 윈도우로 처리하면 각 사이클마다 ${\cal O}(L)$ 번의 연산으로 모든 원소를 갱신할 수 있으므로 한 $f^d$를 ${\cal O}(N)$에 처리할 수 있습니다.

${\cal O}(\lg T)$개의 $f^{2^X}$의 합성으로 $f^T$를 표현할 수 있으므로 총 시간 복잡도 ${\cal O}(N \lg T)$에 문제를 해결할 수 있습니다.

## 코드

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll = long long;

ll a[101010], na[101010]; int n, k;

void f(int d){
	int g = gcd(n, d); int len = n/g; int w = k%(2*len);
	for(int s = 0; s < g; s++){
		int now = 0, l = s, r = s;
		for(int j = 0; j < w; j++) now ^= a[r], r = (r+d)%n;
		for(int j = 0; j < len; j++){
			na[l] = now; now ^= a[l]^a[r];
			l = (l+d)%n; r = (r+d)%n;
		}
	}
	swap(a, na);
}

int main(){
	cin.tie(0);cout.tie(0);ios::sync_with_stdio(false);
	ll t; cin >> n >> k >> t;
	for(int i = 0; i < n; i++) cin >> a[i];
	int d = 1; while(t){
		if(t&1) f(d); t >>= 1; d = (d<<1)%n;
	}
	for(int i = 0; i < n; i++) cout << a[i] << ' ';
}
```
